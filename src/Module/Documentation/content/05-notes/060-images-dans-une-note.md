Une image se colle directement dans la note. Elle est redimensionnée avant l'envoi, dans le navigateur.

![Les images dans une note](../../images/05-notes/notes.png)

## Les deux réglages

- La taille maximale du grand côté, en pixels.
- La qualité de compression, en pourcentage.

## Pourquoi côté navigateur

Une capture d'écran moderne pèse plusieurs méga-octets pour rien. La réduire avant l'envoi économise le transfert et le disque, et rend le collage instantané.
