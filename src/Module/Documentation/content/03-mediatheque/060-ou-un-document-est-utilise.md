Un document ne disparaît pas d'une page sans prévenir : la bibliothèque sait où il sert.

![Où un document est utilisé](../../images/03-mediatheque/ged-documents.png)

## Ce que la liste montre

- Les publications dont il est la vignette.
- Les zones média et les galeries qui le portent.
- Les bannières où il sert de fond.
- Son usage comme logo ou favicon du site.

## Supprimer quand même

Rien n'empêche de supprimer un document utilisé. La zone qui le portait rend alors du vide plutôt qu'une image cassée, ce qui est mieux, mais reste un trou dans une page.
