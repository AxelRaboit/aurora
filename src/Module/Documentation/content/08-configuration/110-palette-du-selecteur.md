Un petit réglage qui évite beaucoup de dérive : la liste des couleurs proposées dans les sélecteurs.

![L'onglet Apparence](../../images/08-configuration/palette-du-selecteur-01-l-onglet-apparence.png)

## À quoi ça sert

Poser la palette du client une fois, pour que les couleurs choisies dans les bandeaux, les agendas et les thèmes soient les siennes, et pas une teinte approchante trouvée dans une roue chromatique.
